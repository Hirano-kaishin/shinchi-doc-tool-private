# 実装に向けた機能メモ

## 生成対象の書類
1. 施工計画書（16項目：表紙 / 工事概要 / 工事内容 / 施工場所 / 計画工程表 / 現場組織票 / 施工体系図 / 使用機械 / 施工方法 / 防災対策 / 防災対策中止基準 / 施工管理計画 / 仮設備計画 / 交通管理 / 当初環境対策 / 現場作業環境の整備）
2. 工程管理表（新地建設の進捗基準で自動割付）
3. 品質管理計画書（ひな形あり）
4. 安全衛生管理計画書
5. 災害防止協議会資料

## 基本方針
- Excelひな形の内容は過去案件（小林松ケ尾 太陽光発電所）ベースの初期値。
- **図面PDFから読み取った内容で上書き**するのが基本動作。
- すべての生成項目は手動修正可能（画面上で編集 → 保存）。

## マスタ（事前登録）
- 社員名簿：氏名・役職・保有資格。現場組織票／施工体系図へ差し込み。
- 資格マスタ：必要資格の一覧・保有者数・更新管理。
- 進捗基準設定：乖離しきい値（±10%）、工程照査頻度、工種別標準歩掛など。

## データの流れ
図面アップロード → AI解析（工事名・場所・工期・工種・数量を抽出）
→ 抽出結果の確認・修正 → 5書類へ反映 → 各画面で手動修正 → PDF/Excel書き出し
